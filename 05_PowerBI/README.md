# Power BI Portfolio Deliverable

The canonical Power BI artifact for this project is:

- [FinTech_FinOps_Control_Reconciliation_Dashboard.pbix](FinTech_FinOps_Control_Reconciliation_Dashboard.pbix)
- [10-page PDF preview](FinTech_FinOps_Control_Reconciliation_Dashboard.pdf)
- [Executive Overview image](FinTech_FinOps_Control_Reconciliation_Dashboard_Executive_Overview.png)

The report uses synthetic portfolio data and demonstrates financial operations monitoring, reconciliation, exception management, control evidence, and validation reporting. It does not contain live customer or production brokerage data.

## Report pages

1. Executive Overview
2. Operational Exposure Monitoring
3. Exception Management
4. Cash Monitoring
5. Security Reconciliation
6. Controls and Audit Readiness
7. Validation Appendix
8. Python Validation and Anomaly Monitoring
9. Model QA Appendix
10. Metric Definitions

## Open the model

Download the `.pbix` file and open it with Microsoft Power BI Desktop. The PDF and PNG files provide GitHub-friendly previews without requiring Power BI Desktop.
